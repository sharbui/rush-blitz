# 設定檔說明（Config Spec）

遊戲的關卡與獎勵門都由文字設定檔驅動，位置在 `src/config/`：

| 檔案 | 用途 |
|------|------|
| `src/config/gates.txt` | 獎勵門輪播清單 |
| `src/config/levels/level1.txt`, `level2.txt`, … | 各關卡波次（放新檔即自動多一關） |

- 以 Vite `?raw` 打包；**編輯後重新整理頁面即生效**，不需重新 build。
- 每行一筆；`#` 之後為註解；空行忽略。
- 敵兵/BOSS 的 type 外型對照見 [`敵兵與BOSS列表.md`](敵兵與BOSS列表.md)。

---

## 一、關卡設定檔 `levels/levelN.txt`

每行一波。波次會平均分佈在該關總時長（`LEVEL_DURATION_MS`，目前 3 分鐘）內。
基本士兵「潮水」會全程持續湧入，與這些波次疊加。

```
type, hp, atk, attackType, speed, count, firstSlot[, reward]
```

| 欄位 | 說明 |
|------|------|
| **type** | 敵兵/BOSS 種類。mobs：`1`坦克 `2`快兵 `3`猛漢 `4`弓手 `5`盾兵；BOSS：`6`恐龍 `7`機器人 `8`惡魔 `9`巨蟲 `10`岩石巨人 |
| **hp** | 絕對血量（純數字），或 `~N` ＝火力相對：約在 **N% 路程**被打死，隨玩家變強自動放大（玩家集中火力時）。 |
| **atk** | 命中（子彈或碰撞）時玩家損失的兵數。 |
| **attackType** | `1`＝直線單發；`2`＝散射 30°（3 發）。（目前僅這兩種） |
| **speed** | 移動單位，×`ENEMY_SPEED_UNIT(26)` = px/s。`3` ≈ 基本兵；BOSS 常用 `2`。 |
| **count** | 一次出現的數量。**BOSS 也用這欄**：單體設 `1`，多隻設 2–3（會自動拉開 `BOSS_SLOT_STEP(10)` 格避免重疊）。 |
| **firstSlot** | 第一隻的垂直格（`1`..`49`，`25`≈中間）；其餘往下 +1 格（mob）或 +`BOSS_SLOT_STEP`（BOSS）。 |
| **reward** | （選填，第 8 欄）擊殺此敵時給予的獎勵，語法同獎勵門：`+N -N *N /N`（兵數）/ `P+N P-N`（威力）。主要給 BOSS 用。 |

### 範例

```
2,10,1,1,6,12,6            # 快兵 12 隻，血10，直線，從第6格起
4,18,1,2,5,10,16           # 弓手 10 隻，散射
1,~70,3,1,3,6,21           # 坦克 6 隻，火力相對血量（約70%路程死）
6,~95,8,2,2,1,25,*4        # 單體恐龍王；散射；擊殺獎勵 ×4 兵
7,~90,6,1,3,2,18,P+2       # 兩隻機甲；擊殺獎勵 威力+2
10,800,10,1,2,1,25,+100    # 固定800血岩石巨人；擊殺獎勵 +100 兵
```

## 二、獎勵門設定檔 `gates.txt`

每行一道門，格式為「**上選項 , 下選項**」。玩家走過上或下車道即取得該選項。
門統一外型，靠**顏色**區分：**藍**＝增益、**紅**＝減益、**灰**＝題目（未知）。

### 選項語法

| 類型 | 寫法 | 意義 | 顏色 |
|------|------|------|------|
| 兵數加 | `+N` | 兵力 +N | 藍 |
| 兵數減 | `-N` | 兵力 −N | 紅 |
| 兵數乘 | `*N` | 兵力 ×N | 藍 |
| 兵數除 | `/N` | 兵力 ÷N | 紅 |
| 威力加 | `P+N` | 武器威力 +N | 藍 |
| 威力減 | `P-N` | 武器威力 −N | 紅 |

### 題目門（灰色）

一行三個欄位：`式1, 式2, 量`。兩個車道各是一條算式；走過**正確**式 → `+量` 兵，走過**錯誤**式 → `−量` 兵。題目門在場時會**暫停螢幕震動**方便讀題。

```
8*8=16,7+2=9,25            # 8*8=16 錯→-25；7+2=9 對→+25
```

### 範例

```
+25,P-1                    # 上：+25 兵(藍)  下：威力-1(紅)
*2,/2                      # 上：×2 兵(藍)   下：÷2 兵(紅)
P+1,+15                    # 上：威力+1(藍)  下：+15 兵(藍)
12-5=6,3*4=12,30           # 題目門(灰)：3*4=12 對→+30
```

> 算式支援 `+ - * /`（先乘除後加減），整數比較。

## 三、相關常數（`src/config/constants.ts`）

| 常數 | 預設 | 作用 |
|------|------|------|
| `LEVEL_DURATION_MS` | 180000 | 每關總長（3 分鐘） |
| `GATE_INTERVAL` | 8500 | 獎勵門出現間隔 |
| `ENEMY_SPEED_UNIT` | 26 | speed 欄位 ×此 = px/s |
| `ENEMY_SLOTS` | 49 | 垂直格數（中間≈25） |
| `BOSS_TYPE_MIN` / `BOSS_SLOT_STEP` | 6 / 10 | type≥6 視為 BOSS、多隻 BOSS 間距 |
| `TIDE_PIERCE_COUNT` | 3 | 每發子彈約穿幾個潮水兵（貫穿） |
| `POWER_TABLE` | 8 階 | 威力表：每階傷害/射速/彈數/七彩色 |
| `WAVE_HP_MAX` | 12000 | `~N` 動態血量上限 |

詳細遊戲設計脈絡見 [`難度與緊湊化規畫.md`](難度與緊湊化規畫.md)。
