# 難度提升 × 畫面緊湊化 規畫文件

> 範圍限制：**美術風格與素材不調整**（沿用 BootScene 程序生成的圖）。
> 本次只動：陣型密度、數值平衡、波次節奏、敵人行為、魔王強化。
> 目標：擺脫「小朋友遊戲」的鬆散感 → 緊湊、有壓力、需要操作。

## 二、畫面緊湊化（佈局，**不碰美術**）

### 2.1 士兵陣型加密
`GameScene.updateSoldierPositions` / `firePlayerBullets`

| 參數 | 現值 | 建議 | 效果 |
|------|------|------|------|
| 列內 Y 間距 | 22px | **13px** | 同樣人數佔垂直空間少 ~40% |
| 欄間 X 間距 | 22px | **15px** | 縱深更密、像方陣 |
| 每欄人數 | 5 | **6** | 同寬度容納更多 |
| 最大可見數 | 20 | **30** | 滿員視覺更壯觀、更密 |
| bob 抖動振幅 | 2.5 | **1.5** | 減少鬆散晃動感 |

> 新增常數：`SOLDIER_GAP_Y = 13`、`SOLDIER_GAP_X = 15`、`SOLDIER_PER_COL = 6`、`SQUAD_MAX_VISUAL = 30`，取代散落在程式裡的魔術數字 22 / 5 / 20。

### 2.2 戰場縱向收緊
- `SQUAD_MIN_Y` 70 → **90**、`SQUAD_MAX_Y` 410 → **400**：把可活動帶略收，逼近戰，留白變少。
- 敵人生成 Y 範圍對齊上面收緊後的活動帶（目前 110 起算），讓子彈與敵人更常處於同一條走廊。

### 2.3 敵人陣型加密
`spawnWave`：欄間距 `col * 38` → **`col * 28`**，讓敵群更像「一堵牆」壓過來，而非稀疏點點。

## 三、難度提升

### 3.1 敵兵會射擊（最大改動，核心壓力來源）
目前只有魔王開火，這是「太簡單」的主因。

- 騎兵（cavalry）獲得低頻直線射擊：進場後每 `1600–2200ms` 朝左發 1 發（沿用 `enemy_bullet` 貼圖，**不需新美術**）。
- 後段波次的精英士兵（標記 `canShoot`）每 `2200ms` 發 1 發。
- 子彈速度沿用 `ENEMY_BULLET_SPEED`，但對一般敵新增較慢值 `ENEMY_BULLET_SPEED_GRUNT = 240`，與魔王彈拉開層次。
- 實作：`spawnEnemy` 接受 `fireRate?` 參數，敵人自帶 `time.addEvent`，敵人被清除時一併 `remove`。

### 3.2 數值重平衡（隨波次遞增）
新增 `waveScale(n)`：HP 與數量隨波次線性放大。

| 項目 | 現值 | 規畫 |
|------|------|------|
| 敵兵 HP | 4 | `4 + floor(wave/2)`（第10波 ≈ 9） |
| 騎兵 HP | 12 | `12 + wave`（第10波 ≈ 22） |
| 敵兵傷害 | 1 | 1（不變，靠數量壓） |
| 騎兵傷害 | 2 | **3** |
| 騎兵速度 | 140 | 140 → 後段波 **170** |

### 3.3 波次節奏收緊
- 波間隔 5–6s → **3–4s**，並讓相鄰波**重疊 spawn**（前一波尾段，下一波已開始進場），消除空畫面。
- 維持 **10 波**架構，但密度與並行度提高。
- 後段（7–10 波）採「士兵牆 + 騎兵突進」混編，逼玩家走位躲彈又要保持火力覆蓋。

### 3.4 獎勵門引入風險取捨
目前雙門都是正向，無腦選大的即可。改為：

- 部分關卡一門高收益、一門低收益（如 `×3` vs `+8`），數值上互有勝負，逼玩家估算當前人數。
- 引入**負面/陷阱門**（如 `-8`、`÷2`）與正向門配對，選錯就掉人 → 真正的決策點。
- 門移動速度 `GATE_SPEED` 200 → **240**，縮短猶豫時間。

### 3.5 魔王強化（沿用三相架構）
- HP 150 → **220**，硬度匹配滿編火力。
- 子彈速度：對魔王彈設 `BOSS_BULLET_SPEED = 380`（比雜兵彈快、有威脅）。
- Phase 1（>66%）：3 叉散射，**加一發直瞄**（4 發）。
- Phase 2（33–66%）：瞄準連射，由 3 發 → **5 發扇形**，射速 950 → **820ms**。
- Phase 3（<33%）：8 方向散射 → **12 方向**（每 30°），射速 550 → **480ms**，並每隔一輪夾帶一次直瞄齊射（彈幕節奏變化）。
- 進場時生成 2 隻護衛騎兵，邊打魔王邊清場。

## 十、設定檔驅動重構（✔ 已實作 — 最新基準）

把關卡、獎勵門、武器全部資料化，敵人分「潮水基本兵」與「設定檔波次特殊型」兩層。

### 10.1 設定檔（可編輯，`?raw` 打包）
- `src/config/gates.txt`：獎勵門輪播，每行一門。
- `src/config/levels/levelN.txt`：關卡波次（放 `level2.txt` 自動多一關）。
- `src/config/loader.ts`：解析 + 內建算式判定器（題目門）。

**門設定格式**（每行 `上選項,下選項`）：
- 人數：`+N -N *N /N`（藍=增益、紅=減益）
- 威力：`P+N P-N`
- 題目門（灰）：`式1,式2,量` → 正確式 `+量`、錯誤式 `-量`（如 `8*8=16`錯→-25、`7+2=9`對→+25）。

**關卡波次格式**：`type,hp,atk,attackType,speed,count,firstSlot`
- attackType：1=直線、2=散射30°(3發)；speed×`ENEMY_SPEED_UNIT`=px/s。
- firstSlot：垂直格 1..`ENEMY_SLOTS(49)`，中間≈25；其餘 +1 遞增。

### 10.2 武器「七彩威力表」（取代 9.2 階級）
- `POWER_TABLE` 8 階（紅→橙→黃→綠→青→藍→靛→紫），每階定義 `dmg/fireRate/bullets/tint`。
- `P+/P-` 門調整威力；HUD `⚡ POWER n/8` 染對應七彩 + 升級橫幅。

**火力公式（方案 A）**：

> 每發子彈傷害 = `威力dmg × ⌈兵力 ÷ 30⌉`

- 只有 30 兵開火（`SQUAD_MAX_VISUAL`），多出的兵力轉成**每發更高傷害**（30 道彈流不變、效能穩）。
- 例（威力1 dmg=1）：30兵→每發1；300兵→每發10；1000兵→每發34。威力 P 再乘上去 → 囤兵 × 升威力雙乘。
- 註：倍率為離散跳階（每滿 30 兵跳一級）；若要平滑或 HUD 顯示實際傷害，再調。

### 10.3 敵人兩層

## 十一、貫穿 × 動態血量 × 小BOSS血條（✔ 已實作）

### 11.1 子彈貫穿
- 子彈帶「剩餘傷害」預算（= 發射當下每發傷害 `bulletDamage()`）。命中扣血後**剩餘傷害仍有就穿透**下一個，耗盡才消失。
- 效果：高威力一發連穿多個弱兵；打高血小BOSS 則停下單獨啃。

### 11.2 雜兵（潮水）HP 隨火力縮放
- 因貫穿會把 HP1 潮水整排掃光，潮水兵 HP 改為 `⌈bulletDamage() ÷ TIDE_PIERCE_COUNT(3)⌉`。
- 不論火力多高，**每發約穿 3 個雜兵**，潮水維持威脅；基礎威力時仍「1發1個」。

### 11.3 設定檔血量：絕對 vs `~N` 相對
- 純數字 = **絕對血量**（固定）。
- `~N` = **火力相對**：HP = 集中火力打到牠的總輸出 × N% → 牠約在 **N% 路程**才被打死，隨玩家變強自動水漲船高（`resolveWaveHp`，clamp 至 `WAVE_HP_MAX 12000`）。
- 估算基於「集中火力」：對準該車道時 `~85` ≈ 85% 路程死；同波多隻分散火力時，未被集中者會衝更近甚至貼臉 → 壓迫感來源。

### 11.4 小BOSS 血條
- 設定檔波次敵兵頭上顯示**血條 + 數字**（綠→橘→紅），中彈即時遞減，隨體型貼頭頂，depth 55（最上層）；潮水兵不顯示。

### 11.5 關卡與 level1 難度曲線
- 關卡總長 `LEVEL_DURATION_MS = 3 分鐘`。
- level1 第 1–2 波絕對小血量暖身；第 3 波起改 `~N` 並逐波加大（`~45 → ~95`），坦克終局幾乎貼臉才死。

### 11.6 待實機微調旋鈕
- `TIDE_PIERCE_COUNT 3`（調大=雜兵更脆、穿更多）。
- 各波 `~N`（整體太近/太遠時調）。
- `WAVE_HP_MAX 12000` 安全上限。
